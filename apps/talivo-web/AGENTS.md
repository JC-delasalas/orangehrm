# Talivo React boundary
Follow the repository's license and preserve upstream files. This directory intentionally uses React/Next.js, not the upstream Vue page conventions. Do not edit `.agents`, the root Dockerfile, `src/client`, PHP plugins or existing deployments to make this starter run.

This is a front-end foundation with synthetic data, not a live product. Keep all mock behavior labeled. No customer PRDs, private employee records, credentials, original designs or confidential files should be committed here.

Managers author and submit assessments. HRBPs review assigned submissions, request evidence, and record clearance only within delegated authority. A workspace change never creates authority. HR clearance is not a final rating or an external action.

Use the separate company, actor, workspace and population scope. Enforce these on the future server and every model tool. Current client checks are demonstrations, not authentication or production security.

Run `npm test`, `npm run typecheck`, and `npm run build` after installing dependencies. A global TypeScript compiler can run the domain tests offline. Do not call this a full React build or browser test.
